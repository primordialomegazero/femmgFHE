## Security Model

Spiral Fractal iO security is **structural, not computational**:

- **φ·ψ = -1** algebraic identity guarantees self-cancellation
- **Commutative reconstruction** ensures order-independent output
- **Spiral Bootstrap** never exposes plaintext during noise reset
- **GF-N Encryption** with Cassini invariant > 0.1 per layer
- **Seed Tree** provides branch isolation via irrational φ-branching

For full details: [`docs/SECURITY_MODEL.md`](docs/SECURITY_MODEL.md)
